# LeiloesTDSat

## Sobre o projeto
Sistema desenvolvido na UC11 do curso Técnico de Desenvolvimento de Sistema realizado pelo SENAC.
Esse novo projeto é referente a uma casa de leilões com interesse em informatizar suas rotinas. 
 

## Tecnologias utilizadas
- **Java** 
- **MySQL** (Banco de dados relacional para armazenamento das informações)
- **Git e GitHub** (Controle de versão e hospedagem do código-fonte)
